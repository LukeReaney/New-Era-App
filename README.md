First major personal project I took on. This is a progressive web application for a local mma gym. 

This project tested me with many challenges and new experiments. 

I explored linking a database to a web app , authentication for logging in and checking against a database. 
For this I used firebase which allowed easy integration into the project using a key. 

The app produced amazing results in pushing me to learn more concepts and listen to advice from users of the app.
